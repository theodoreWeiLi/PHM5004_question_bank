### Directory Overview

This directory contains a question bank for a Genetics & Genomics course (PHM5001). The questions are in a multiple-choice format and cover various topics within the subject.

### Key Files

*   `question_bank1.md`: A multiple-choice question bank on Genomics, Sequencing, and Population Genetics. Each question includes the question, options, the correct answer, and a brief analysis.
*   `question_bank2.md`: A multiple-choice question bank on Genetics & Genomics. Each question includes the question, options, the correct answer, and a brief analysis.

### Usage

This directory is used to store and review questions and answers for the PHM5001 course. The markdown files can be used for self-assessment and studying.
